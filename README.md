# Калькулятор расчета баллистики blstcs.ru v3.6 Multi-Sync

Версия 3.6 с расширенным функционалом:
1. **Справочники баллистики и слоев**: возможность менять названия любых материалов баллистики, цену за 1 м², наценку и варианты слойности прямо в интерфейсе (с превью-бейждами).
2. **Очистка истории по аккаунту**: кнопка «Очистить свои записи» удаляет расчеты только текущего пользователя, сохраняя расчеты коллег.
3. **Фоновая автосинхронизация 1 минута**: калькулятор автоматически раз в минуту выгружает новые локальные расчеты в Google Таблицу и забирает свежие расчеты других сотрудников.
4. **Синхронизация справочников и цен через лист «Настройки»**: все параметры, цены, ткани и слои сохраняются в Google Таблицу на лист «Настройки» и автоматически обновляются на всех рабочих местах.
